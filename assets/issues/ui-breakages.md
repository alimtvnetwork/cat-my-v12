# UI Breakages in Modern Screen and Compact Mode

Based on user feedback on August 12:

1. **Control Button Overlap**: In the modern screen, the control button goes "far away from the screen" (likely overflowing or misaligned).
2. **Layer Numbers**: The layer numbers look unprofessional and need a redesign/fix in the modern screen.
3. **Missing Window/Setting Menu**: The "Window" button and settings are missing from the menu side. The Window menu should show how many windows are open.
4. **UI Switcher**: There should be a button to switch the UI (Standard vs Modern), which is currently missing or broken.
5. **Compact Screen Breakage**: The UI looks broken when resized to a compact screen. Controls go out of bounds and are not fluid/compact.

These issues need to be resolved in the next UI polish pass.
