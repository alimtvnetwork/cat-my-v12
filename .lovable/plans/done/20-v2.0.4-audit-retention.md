## Context

Audit rows accumulate unbounded today. `E_SEC_*`, `RuleBundle*`, `CaptureError`, license, and admin-write events all land in the audit sink with no retention window, no rotation policy, and no export contract. Left alone this slows queries, forces emergency truncation, and destroys evidence trails needed for future audits. v2.0.4 locks the retention contract, the rotation worker, the Ops surface, and the export path before we ship anything that raises audit volume further (rule bundle import, cloud catalog).

Prior plan: Plan 19 shipped `derive_denial_defaults`, `E_SEC_DENIAL_BURST` promotion, hot-reload, and the read-only Ops tile at v2.0.3 (archived at `.lovable/plans/done/19-v2.0.3-denial-tuning.md`).

## Steps

1. Author `spec/21-app/71-audit-retention.md` §71.1 Purpose + Scope. Cover: rows in scope (all `audit_events` categories including `E_SEC_*`, `RuleBundle*`, `CaptureError`, license, admin-write), non-goals (no export of raw payloads outside the sink, no cross-tenant aggregation), and link back to `spec/21-app/41-logging.md` and `spec/21-app/44-security-privacy.md`.
2. §71.2 Retention Windows. Lock PascalCase policy names `RetentionShort` (30 days), `RetentionStandard` (180 days), `RetentionLong` (400 days), and `RetentionForensic` (900 days, admin-write only). Map every event category to exactly one policy. Forbid per-row overrides.
3. §71.3 Rotation Worker Contract. Define the worker cadence (default 6h, min 1h, max 24h), the transactional delete batch cap, the `CorrelationId` propagation rule for rotation runs, and the failure/back-off shape. Pin errors `E_AUDIT_RETENTION_LOCKED`, `E_AUDIT_RETENTION_BATCH_OVERRUN`, `E_AUDIT_RETENTION_CLOCK_SKEW`.
4. §71.4 Config Surface. Extend `spec/21-app/27-config-surface.md` with `Audit.Retention.*` keys (policy overrides limited to raising, not lowering, retention). Lock validation rules and hot-reload behavior (mirror Plan 19 §5).
5. §71.5 Export Contract. Define `POST /internal/audit/export` server function (TierTwo+) producing a signed `.catauditjsonl` bundle with manifest, `sha256`, and event count. Reuse the `.catrules` container conventions from `spec/21-app/70-rule-bundle-import-export.md` §70.3 where they overlap.
6. §71.6 Ops UI + Counters. Add read-only tiles to `src/routes/ops.tsx`: last rotation `Ts`, rows purged (last 24h), oldest surviving row per policy, next scheduled run. Poll every 15s via `getAuditRetentionStatus`.
7. Implement rotation worker in `app/core/audit/retention_worker.py` (batched delete inside a single transaction per policy). Add unit tests locking window boundaries and clock-skew rejection in `tests/unit/test_audit_retention_worker.py`.
8. Implement `getAuditRetentionStatus` server function under `src/lib/audit-retention.functions.ts` with `requireCaptureAdmin`. Wire the Ops tiles to it.
9. Implement export server function `exportAuditBundle` under `src/lib/audit-export.functions.ts` with `requireCaptureAdmin`, size caps, and Ops event `AuditBundleExported` (log `payloadSha256Prefix8` only, per Plan 16 §70.11 convention).
10. Close-out: evidence bundle `.lovable/memory/v2/plan20/40-evidence.md`, pin `v2.0.4` in README/CHANGELOG/RELEASE_NOTES, archive Plan 20 to `.lovable/plans/done/`, register the next prompt.
