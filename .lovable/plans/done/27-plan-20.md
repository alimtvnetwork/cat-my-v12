8. Unit tests `tests/unit/retention_worker_test.py`: eligible-only deletion; prune-is-audited row present; non-admin write denied and not persisted; deterministic clock respected; failure path emits `E_SEC_RETENTION_FAILED`.
9. Unit tests `tests/unit/audit_sink_prune_test.py`: rows outside policy untouched; size-based prune drops oldest first; empty-policy no-op; concurrency-safe (single writer).
10. TypeScript server function `src/lib/retention.functions.ts` (`writeRetentionPolicy`) using `requireSupabaseAuth` + admin gate, mirroring `writeSelectedDevice` shape and `toCaptureError`-style typed errors.
11. Wire `src/routes/settings.index.tsx` retention section to `useServerFn(writeRetentionPolicy)`; keep localStorage as instant mirror; surface `E_SEC_ROLE_DENIED` inline with `aria-live="polite"`.
12. Add `OpsEventCode` entries `I_SEC_AUDIT_PRUNED` and `E_SEC_RETENTION_FAILED` to `src/lib/ops.shared.ts`; emit via `appendOpsEvent` from the retention write path denial branch (parity with Plan 26 Step 7).
13. Add `RetentionAuditPanel` to `src/routes/ops.tsx`: filtered on `subject='settings.audit.retention'` OR `code IN (I_SEC_AUDIT_PRUNED, E_SEC_RETENTION_FAILED)`; columns Time / Code / Actor / Prior / Next / CID / Detail.
