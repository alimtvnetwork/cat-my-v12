## Context

Selected via `.lovable/spec/commands/07-plan-from-backlog-top.md` from `.lovable/memory/v2/01-ranked-backlog.md` **Rank 1: Real vendor SDK integration behind `VendorDeviceIO`**. Plans 15 / 17 (v2.0.1 / v2.0.2) delivered the initial Pylon path plus stub Spinnaker and Vimba adapters, but the Rank 1 acceptance criteria are not fully met: fault-mode integration tests against a physical camera in CI-lite, uniform vendor-exception mapping to `E_HW_TIMEOUT` / `E_HW_DISCONNECTED` / `E_HW_UNKNOWN`, and the perf harness reporting median FPS >= 77 are not yet proven. This plan closes those gaps and pins parity across all three vendor adapters behind `VendorDeviceIO`.

## Steps

1. Baseline audit: enumerate current adapter parity across Pylon / Spinnaker / Vimba (methods implemented, exception mapping, discovery hookup). Write findings to `.lovable/memory/v2/plan25/00-adapter-parity-baseline.md`. See `./subtasks/25-v2.0.7-vendor-sdk-hardening/ss-01-parity-audit.md`.
2. Lock the `VendorDeviceIO` contract: freeze the method set, fault-mapping table, and lifecycle in `spec/21-app/50-capture-modules.md`; cross-link from 63/64/65. See `./subtasks/25-v2.0.7-vendor-sdk-hardening/ss-02-contract-lock.md`.
3. Implement Spinnaker adapter to parity with Pylon (open/close, single-frame, streaming, timeout, disconnect handling).
4. Implement Vimba adapter to parity with Pylon; verify vendor exceptions raise `E_HW_TIMEOUT` / `E_HW_DISCONNECTED` / `E_HW_UNKNOWN` uniformly. See `./subtasks/25-v2.0.7-vendor-sdk-hardening/ss-03-vimba-fault-map.md`.
5. Wire vendor discovery (`spec/21-app/66-v2-vendor-discovery.md`) to return `vendor`, `serial`, `model`, `transport`, `display_name` from all three SDKs; unknown IDs raise `E_CFG_UNKNOWN_DEVICE`.
6. Fault-mode integration tests (CI-lite): mock USB unplug, timeout, unknown vendor error for each adapter; assert code + audit row. See `./subtasks/25-v2.0.7-vendor-sdk-hardening/ss-04-fault-tests.md`.
7. Perf harness: median FPS harness against a physical camera (or replay fixture when hardware absent); assert median >= 77 fps and record p95. See `./subtasks/25-v2.0.7-vendor-sdk-hardening/ss-05-perf-harness.md`.
8. Audit trail: settings write for `capture.device` emits `I_SEC_ADMIN_WRITE`; verify via `/ops` and durable audit sink; snapshot into memory.
9. Rescore `spec/21-app/50-51.md` and vendor specs 63-66 with the Blind-AI rubric; expect mean >= 90 and 0 blockers. Write to `spec/25-app-audit/latest/` and update `90-findings-summary.md`.
10. Close-out: bump minor version, update `changelog.md` / `release_notes.md` / `readme.md` banner, and move this plan `pending -> done`. Update `.lovable/memory/v2/01-ranked-backlog.md` marking Rank 1 as delivered.
