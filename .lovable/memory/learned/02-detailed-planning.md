# Learned Patterns: Detailed Planning as a Brain

1. **Detailed Task Generation:** A plan cannot be shallow. When defining a multi-agent loop, every subtask must be written "in detail manner... what to fix, what to make changes." It must include a root cause analysis and deep contextual information so the agent executing it knows exactly what to do.
2. **Pending vs Completed:** Newly generated plans must remain as `pending`. Do not erroneously mark them as `completed` during the planning phase.
3. **Verbatim User Directive:** "That means you will plan as a brain, okay? ... It needs to be very clear, and those needs to be pending task, not completed task... The UI is not flexible. I cannot resize the stuff on the right side panel... the coloring of the buttons. It looks like faded... especially the Cancel button... start like the grayscale version... no overlapping... everywhere there should be a error model."
