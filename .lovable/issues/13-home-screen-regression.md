# Home screen regression

Slug: home-screen-regression
Status: closed
Closed-by: Plan 75
Closed-on: 2026-07-18
Created: 2026-07-16

## Symptom

The home screen is gone or no longer matches the previously discussed four-entry home flow. The user reports the app reverted to old or bad UI patterns instead of keeping the home screen as the central launcher.

## Expected

Route `/` shows a home screen with the core workflow entries: Projects, Setup, Trial run / image testing, and AI testing / review. The user can return to this screen at any time.

## Actual

The current direction in Plan 36 replaces home with a Jobs + Tasks operator screen and removes the home launcher concept.
