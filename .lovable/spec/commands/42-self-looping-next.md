# Command: Self-looping via Next

**Verbatim User Directive:**
> "Hey, you have to auto loop. Next is something that if it breaks, then I would say. Otherwise, you have to just go and loop yourself. I would just say next and you self-loop yourself. Do you understand what I'm saying? Can you please do that for me"

## Meaning
When the user says "next" or "Continue", the AI should continuously self-loop and execute consecutive pending tasks from the active plan without waiting for individual prompts for each step, unless there is a breakage or failure, in which case the AI should stop and wait for explicit guidance.
